## Como compilar y ejecutar 

```
    mkdir -p bin
    gcc -Wall -o bin/e1 e1.c
    ./bin/e1
```

Para los ejercicios 5 al 10, se puede utilizar de la siguiente manera:

```
    ./bin/e5 < prueba.txt
    ./bin/e6 < largas.txt
```
